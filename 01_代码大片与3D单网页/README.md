## 一、三大现象级开源项目直达与核心用法

### 1. `heygen-com/hyperframes`（★ 84,892 · `Apache-2.0`）
- **仓库地址**：https://github.com/heygen-com/hyperframes
- **一句话定位**：`Write HTML. Render video. Built for agents.` 专为 AI Agent 设计的高帧率 HTML 转成片渲染底座。
- **为什么值得用**：传统录屏靠实时 `requestAnimationFrame` 极易因 CPU 波动掉帧卡顿；确定性代码视频的核心是暴露 `window.seek(t)` 时间轴函数，让无头浏览器逐帧精确步进截图后由 `ffmpeg` 合成为丝滑 60fps MP4。
- **零丢帧 Headless Chrome 捕获黄金参数**：
  ```bash
  # 强制开启 SwiftShader 软件光栅化 + 单并发步进，杜绝 GPU 上下文切换闪黑帧
  npx playwright screenshot --browser=chromium \
    --launch-options='{"args":["--use-gl=angle","--use-angle=swiftshader"]}' \
    demo.html frame_0001.png
  ```

### 2. `DeaglePC/ArtInMotion`（零生图大模型 · 20 种中西手绘有声大片）
- **仓库地址**：https://github.com/DeaglePC/ArtInMotion
- **核心技术拆解**：
  1. **不调任何付费生图 API**：纯靠 `NumPy` + `Sobel` 边缘梯度算子识别人像结构走向，顺着五官轮廓一笔笔落笔（而非呆板网格扫描）；
  2. **20 种画材物理拟真**：涵盖彩铅（自动计算明度残差补高光白点）、水墨、木刻版画、暖光灯箱沙画（按沙层厚度指数衰减模拟真实透光）；
  3. **音画自合成**：前 3 笔同步触发真实纸张摩擦音效，随后切入程序化随机和弦钢琴配乐，片头自带 `1.2s` 成品定格先导钩子。

### 3. `apekshik/three-nanite`（`MIT` · 浏览器跑 1.84 亿三角面）
- **仓库地址**：https://github.com/apekshik/three-nanite
- **亮点**：把虚幻引擎 5 的 `Nanite` 簇级多细节层次（Cluster LOD）搬进了纯网页 `Three.js`，同屏 `1.84 亿` 三角面实际每帧仅需绘制不到 `200 万` 面即可无裂缝丝滑交互。

## 二、几百 KB 单文件 3D 网页：5 套中文万能 Prompt 模板

> 原理就像“HTML 是几百 KB 的菜谱，打开网页瞬间由本地显卡现炒出一整个世界”。直接复制下方任一提示词发给 Claude / Gemini / GPT / Qwen4-Max 即可生成单文件离线可玩的 `.html`：

### 模板 1：微缩机械海岛与昼夜潮汐（单文件 Three.js）
```text
请写一个完全独立、零外部图片/模型依赖的单文件 HTML（仅通过 CDN 引入 Three.js），构建一座悬浮在半空的微缩蒸汽机械灯塔海岛：
1. 几何与材质：全部用程序化几何体与自定义 Shader 组合出礁石、旋转黄铜灯塔齿轮、拍岸白沫海浪（Vertex Shader 正弦叠加波浪）与低多边形海鸥；
2. 光影交互：右上角提供一个极简昼夜滑块（正午晴空 -> 黄昏暖金 -> 深夜探照灯光束扫过海面），支持鼠标拖拽环绕与滚轮缩放；
3. 工程红线：严禁引用任何不存在的外部 .glb/.jpg 链接，打开单个 HTML 文件必须 60fps 直接运行零报错。
```

### 模板 2：桌面级透明机械腕表擒纵机构拆解台
```text
请生成一个单文件离线可运行的交互式 3D 机械表芯拆解页（HTML + Three.js）：
1. 精确啮合：用程序化挤出齿轮（ExtrudeGeometry）构建发条盒、中心轮、三轮、秒轮与摆轮游丝擒纵叉，齿数比严格遵循角速度守恒，绝不穿模打滑；
2. 交互面板：提供「爆炸拆解滑块（Explode 0%~100%）」、「0.1x 慢动作微距观察」与「蓝宝石表壳半透明剖切」三个开关；
3. 视觉质感：深炭暗房背景（#0B0E14），黄铜齿轮、蓝钢螺丝与红宝石轴承采用物理金属粗糙度材质（MeshStandardMaterial）。
```

### 模板 3：97KB 风格实时流体波纹庭院（WebGL / Shader）
```text
请用单个 HTML 文件实现一个交互式枯山水与锦鲤水池俯视庭院：
1. 水面物理：使用双缓冲 Framebuffer（Ping-Pong FBO）求解二维波动方程，鼠标划过水面或点击落雨时产生真实反射与干涉波纹，水底鹅卵石随法线折射扭曲；
2. 程序化锦鲤：3 条由多节脊椎正弦摆动驱动的红白锦鲤在水中自主转向游动，尾鳍划水时自动激发微弱水波；
3. 保持代码干净紧凑，零外部贴图依赖。
```

### 模板 4：复古 8-Bit CRT 街机厅微型走廊
```text
请用单个 HTML 文件构建一间 1990 年代霓虹微光复古街机厅角落（Three.js）：
1. 3 台并排木纹街机框体，每台街机的弧面玻璃屏幕实时运行一段独立的 2D Canvas 迷你像素动画（太空射击 / 弹球 / 贪吃蛇），屏幕自发光照亮前方地面；
2. 后期效果：适度微光（UnrealBloomPass）与地面微弱潮湿镜面反射，严禁刺眼紫粉渐变；点击任一街机镜头平滑推近至屏幕正前方可按键试玩。
```

### 模板 5：「独立美术指导子 Agent」多角度截图盲审迭代提示词
> 当第一版 3D 网页跑通但看着像积木时，**不要在同一个上下文里空口喊“改好看点”**，开一个干净的新会话把 4 张不同角度截图喂进去：
```text

请只根据画面真实呈现效果（忽略代码有多复杂），逐一指出：

```
