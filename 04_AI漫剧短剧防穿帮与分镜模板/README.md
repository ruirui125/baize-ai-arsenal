## 一、为什么 90% 的 AI 短剧一眼穿帮被划走？（三大致命细节）

在平台转向**「有效完播时长结算」**后，单纯换脸拼图剧已大面积下架，真正跑出千万至十亿级播放的长线剧集，核心全赢在**连续镜头不跳戏**：

1. **定妆漏写「鞋子与下装」**：生图提示词只写上半身服饰，导致同一个角色第 1 镜穿皂靴、第 2 镜变草鞋、第 3 镜甚至穿现代运动鞋；
2. **跨镜头左右手道具瞬移**：上一镜右手提灯笼朝左门走，下一镜变成左手提灯笼朝右窗站；
3. **多宫格拼板误喂图生视频**：把三视图拼图原封不动塞进视频首帧，结果视频前 2 秒画面还带着白色分格边框。

## 二、可直接复制的「角色全身锁死定妆卡」模板

每建一个核心角色，强制填满以下 6 项硬锚点并在全集分镜中固定引用：

```markdown
【角色定妆锁死卡 · ID: CHAR_01】
- 骨相与年龄：26岁东亚青年男性，清瘦骨相，剑眉窄脸，左眉尾有一道浅淡旧痕（固定面部识别锚点）
- 发型发饰：乌黑半束高马尾，木质素簪固定，两侧无碎刘海遮眼
- 上装内搭：深青色粗麻交领短褐，袖口缠深褐皮质护腕（做旧磨损质感）
- 下装与鞋靴（必写防穿帮！）：炭黑色束口麻布长裤 + 黑色千层底皂靴（靴筒裹绑腿，严禁出现现代皮鞋底）
- 常驻随身物：右腰侧斜挂一枚磨损黄铜腰牌，背负长条灰布包裹
- 禁用负面项：禁止华丽金丝刺绣、禁止浓妆磨皮滤镜、禁止多余手指或现代拉链扣件
```

## 三、`Seedance 2.5` 保五官比例长镜头 & 前片终态无缝接续公式

### 1. 单镜头运动不崩脸万能结构
> **公式**：`[景别与机位起幅] + [人物核心微动作（每次不超过2个连续动作）] + [道具所在手别与朝向契约] + [环境光影与物理交互] + [镜头运动轨迹与落幅姿态]`

**实战示例**：
```text
中近景平视跟拍，26岁深青短褐青年右手稳提一盏微晃的油纸灯笼，沿潮湿青石板巷由右向左缓步前行；暖黄灯火照亮他紧绷的侧脸与靴底溅起的细碎水花，夜风吹动深青衣摆向后轻扬；摄影机以稳定器平滑后拉转半侧面跟随，镜头落幅停在他驻足抬头望向右侧木门牌匾的背影，五官骨相与面部比例全程稳定自然。
```

### 2. 多镜头长戏「前片终态快照」无缝接续四步法
1. 第 `N` 镜视频生成完毕后，用 `ffmpeg` 提取最后第 1 帧高清静态图（`tail_frame_N.png`）；
2. 在分镜账本登记第 `N` 镜结束瞬间的 **`[持物手别：右手提灯 | 面朝方向：画面右侧木门 | 情绪终态：警觉凝视]`**；
3. 若第 `N+1` 镜为同机位顺接动作，直接拿 `tail_frame_N.png` 作为第 `N+1` 镜首帧输入；
4. 若第 `N+1` 镜需切反打特写，将 `tail_frame_N.png` + 角色全身定妆卡一同作为多模态参考图输入，并在提示词首句显式锁死上一镜终态手别与视线方向。
