## 高阶指挥透镜快捷触发协议 (`#L1` ~ `#L10`)

当我在指令中提及以下 `#L1` ~ `#L10` 编号时，请严格切换至对应的深度思考与工程审计模式，禁止敷衍作答：

- **`#L1` [第一性原理]**：从第一性原理出发，剥离表象补丁，定位物理/字节级最本质根因并彻底修复。
- **`#L2` [先对齐再出3方案]**：先提出不超过 3 个关键澄清问题对齐我的偏好与约束，确认后再给出 3 版真正正交的备选方案（含取舍对比）。
- **`#L3` [质疑问题定义]**：不要默认我提出的问题定义就是正确的。先分析我真正想解决的底层目标，判断我是否把症状误认为原因、把手段误认为目标；若有更值得解决的真问题，直接指出。
- **`#L4` [推演二三阶影响]**：不要只看直接效果。继续推演该改动的二阶、三阶连锁反应，重点评估对上下游模块、真实用户行为、系统复杂度与长期维护成本的潜在冲击。
- **`#L5` [跨领域借镜]**：跳出当前细分领域，检索其他成熟工程或学科中是否存在同构难题的经典解法，用跨领域视角给出最优解。
- **`#L6` [最强反对者红队]**：先假设你当前最得意的方案是错的。站在最强反对者角度寻找能推翻它的证据、反例、并发竞态与极端边界，重新评估并给出更稳健的解法。
- **`#L7` [Git考古清包袱]**：结合 Git 历史、关键提交与架构演进，区分哪些设计是有意护栏、哪些是历史妥协、哪些是为解决早已消失的问题而留下的死包袱，列出可安全清理或归档的清单。
- **`#L8` [陌生高工认知审计]**：假设明天一位完全不了解本项目但水平极高的工程师接手，评估其认知成本；揪出命名歧义、过度抽象、职责缠绕或文档过期之处，给出降维简化方案。
- **`#L9` [慢链路瓶颈剖析]**：全面扫描近期提交与核心执行链路，定位最拖慢研发或运行速度的 Top 瓶颈，给出可量化的提速方案。
- **`#L10` [返工复盘转护栏]**：复盘近期的 Bug、返工、回滚与重复修改，提炼背后的结构性共同根因（拒绝流水账），将防复发措施直接落地为自动化门禁脚本、项目规则或标准 Skill。
