## 一、开源工具官方获取地址与首次打开避坑

- **GitHub 开源主页（GPL v3 协议）**：`https://github.com/itsfatduck/optimizerDuck`
- **免安装单文件直达页（Releases）**：`https://github.com/itsfatduck/optimizerDuck/releases/latest`
  - 普通电脑（绝大多数 Intel / AMD 处理器）下载：**`optimizerDuck-Windows-x64-2.29.0.exe`**（约 `83.3 MB`，之所以有八十多兆是因为把 `.NET 10` 运行库直接打包进了单文件里，双击免装任何环境）。
- **首次打开必做的 3 件事**：
  1. **跳过蓝色拦截窗**：因个人开源作者未购买高价商业数字签名证书，首次双击弹出蓝色保护框属正常现象，点 **「更多信息」→「仍要运行」**，并在弹出的管理员权限框点「是」；
  2. **切换简体中文**：点左下角齿轮 **`Settings` → `Language` → 选 `简体中文`**，全界面 814 条说明即刻变成中文；
  3. **先建系统还原点**：首次调整前按软件提示点一下创建还原点（软件自己也会在 `%LocalAppData%\optimizerDuck\Revert\` 下为每个开关单独保存一份 JSON 后悔药，随时可单条一键撤销）。

## 二、普通办公电脑「闭眼放心开」的 6 项绿牌设置（`Safe` 安全级）

打开左侧 **「系统优化（Optimize）」**，建议**只挑带绿色 `安全 (Safe)` 标签**的以下 6 项开启（点开关前可先点卡片右下角的 **`</>` 图标**，亲眼看清它到底改哪条注册表）：

1. **【性能】优先前台活动应用（Prioritize Active Applications）**：把 CPU 资源优先倾斜给你当前正在打字、做表或开会的窗口。
2. **【隐私】关闭 Windows 遥测与错误报告 / 广告 ID**：关掉系统后台每天偷偷打包上传使用习惯的 `DiagTrack` 遥测通道与个性化广告追踪。
3. **【冗余软件与服务】阻止预装冗余软件（Disable Preinstalled Apps）**：锁死注册表 `ContentDeliveryManager` 四项自动静默安装开关，防止系统更新后又偷偷往开始菜单塞推广小游戏。
4. **【用户体验】加速文件资源管理器与菜单**：将菜单弹出延迟 `MenuShowDelay` 设为 `0`，右键和打开文件夹明显更跟手。
5. **【用户体验】禁用开始菜单网络搜索 & 设置页 Microsoft 365 广告**：搜本地文件名时不再卡半天去调必应网页结果。
6. **【AI（仅 Win11 24H2+）】禁用 Click To Do 屏幕覆盖层**（如果不希望系统定时给屏幕拍快照存档，可顺手关掉 `Windows Recall`）。

## 三、零号真机扒源码揪出的「三大千万别乱碰雷区」

1. **❌ 雷区一：【冗余软件与服务】里的红色 `高风险 (Risky)`「优化系统服务」总开关 —— 办公电脑绝对别开！**
   - **源码真相（`BloatwareAndServices.cs` 第 76~317 行）**：它不是分开的开关，而是一口气批量修改 **240 项系统服务**！其中会把打印后台（`Spooler`）、局域网文件共享（`LanmanServer`）、本地文件搜索（`WSearch`）、系统推送通知（`WpnService`）全部降为手动，并把 `ssh-agent` 与跨时区自动对时（`tzautoupdate`）直接禁用，极易导致公司共享打印机或内网盘失灵。
2. **⚠️ 雷区二：【电源管理】里的「安装自定义电源计划」—— 容易触发任务管理器 `100% CPU` 假警报！**
   - 开启后部分电脑打开任务管理器会显示 CPU 永远卡在 `100%`（GitHub `Issue #29` 已知显示 Bug，实际并不发热耗电，但看着非常吓人，笔记本还会缩短续航，普通办公本没必要开）。
3. **⚠️ 雷区三：【冗余软件（Bloatware）】卸载页 —— 只点「全选安全项」，别手滑删黄色 `谨慎` 项！**
   - 绿色安全项（如自带天气、资讯、纸牌、地图、反馈中心、Clipchamp）可以放心清理；
   - **黄色 `谨慎 (Caution)` 项千万留着**：里面包含计算器、记事本、截图工具（`ScreenSketch`）以及 **`HEVC / VP9 / WebP` 视频与图片解码扩展**，一旦误删会导致电脑打不开手机传过来的照片或视频！

## 四、不装任何第三方软件：Windows 原生 3 分钟手工减负法

如果你的电脑只是轻微发卡，连上面这个单文件工具都不用下，直接按这三步用系统自带入口就能清掉八成负担：
1. `Ctrl + Shift + Esc` 打开任务管理器 → 切到左侧 **「启动应用」** → 把除输入法、声卡驱动、微信之外显示「已启用」的开机自启软件全部右键改为 **「禁用」**；
2. `Win + I` 打开系统设置 → **「隐私和安全性」→「诊断和反馈」** → 关掉「发送可选诊断数据」；
3. **「系统」→「存储」→「临时文件」** → 勾选更新清理与临时缓存一键清空。
