## 一、单张静态二次元立绘 → 会眨眼/对口型/发丝摆动的动态角色（4 款 MIT 开源工具链）

日本独立开发者 `@shinshin86` 将自己把「一张静态二次元插画变成可互动 AI 角色」的全套底层工具全部以 **MIT 协议** 开源，均针对 Claude Code / Codex 命令行协作做了友好适配：

| 流程步骤 | 开源仓库（MIT） | 一句话核心能力 |
| :---: | :--- | :--- |
| **第 1 步：单图拆图层** | **[`shinshin86/still2rig-psd`](https://github.com/shinshin86/still2rig-psd)** | 输入 1 张静态二次元角色立绘，自动拆分五官、前发、后发、躯干并输出带质量校验的结构化分层 `.psd` |
| **第 2 步：免软件直出动态** | **[`shinshin86/mesh-avatar-studio`](https://github.com/shinshin86/mesh-avatar-studio)**（★2.4k） | 无需安装复杂的商业绑定软件，直接把 1 张插画生成支持自然眨眼、说话口型同步与头发物理摇曳的 2D 网格角色 |
| **第 3 步：JSON 追加新动作** | **[`shinshin86/live2d-add-motion-sample-web-ui`](https://github.com/shinshin86/live2d-add-motion-sample-web-ui)** | 不用打开 Cubism Editor，在网页端直接编辑轻量 JSON 就能给已有 Live2D 模型注入新表情与肢体动作 |

## 二、零手写代码手搓「单网页 3D 可玩小游戏」两步法万能 Prompt 模板

### 第一步：先逼 AI 写出完整玩法、数值与反馈设计稿（禁止一上来直接写代码！）
```text
我想做一个单文件 HTML + Three.js 就能直接在浏览器流畅运行的 3D 休闲解压/肉鸽小游戏，核心主题是：【在此填入你的点子，例如：一只胖橘猫在房间里限时推倒物品拆家 / 桌面弹珠肉鸽自走棋】。

请先不要写代码！先帮我输出一份结构严密的可玩原型设计文档，必须明确：
1. 核心 30 秒爽感循环（玩家每 3 秒钟点击或操作什么？屏幕给出什么粒子、震屏、音效反馈？）；
2. 三阶段难度与升级递进（前 1 分钟怎么零门槛上手，第 3 分钟怎么出现夸张的连锁爽点？）；
3. 零外部资产实现方案（所有角色、道具、光影一律使用 Three.js 几何体组合 + 程序化材质/着色器 + WebAudio 合成音效生成，确保双击单个 index.html 100% 离线可玩，绝不引用不存在的外部贴图路径）；
4. 列出最容易出现穿模、视角卡死或手机端误触的 5 个边界坑及规避参数。
```

### 第二步：试玩官四轮迭代口令（把自己当挑剔玩家，只提体感不改语法）
生成首版 `index.html` 在浏览器打开试玩 3 分钟后，复制以下模板做精准体感打磨：
```text
我刚试玩了第一版，核心循环跑通了，但作为真实玩家有 4 个明显卡手的地方，请在不破坏现有正常功能的前提下一次性修复并输出完整单文件：
1. 【打击感/爽感】：击中目标时太软绵绵了，请加上 80ms 顿帧（hit-stop）、相机轻微抖动、受击闪白与浮动伤害数字；
2. 【镜头与手感】：移动时镜头跟得太死容易晕，请改成带阻尼平滑跟随，并把碰撞体积放大 15% 防止擦边漏判；
3. 【主角精致度】：当前主角太像简陋方块了，请单独写一段精细的多部件组合网格（加入呼吸起伏、移动倾斜与尾巴/披风延迟跟随物理）；
4. 【自检要求】：输出前请自行静态检查所有变量初始化顺序与窗口 Resize 自适应，确保控制台 0 报错。
```
