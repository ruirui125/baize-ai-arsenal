## 一、7天拿下5个面试：10条「毒舌招聘总监」改简历与模拟拷问话术

### 1. 扒透招聘启事背后的潜台词
```text
这是目标公司的岗位招聘说明：【粘贴招聘要求】。
请你扮演一位在这行干了15年、刚开掉上一个不称职员工的业务部门总监。忘掉官方客套话，用大白话告诉我：
1. 这个岗位招人进来头三个月最急着擦屁股的3件脏活累活是什么？
2. 面试时候选人说哪句套话会让你心里立刻扣分？
3. 什么样的过往经历细节会让你眼前一亮当场想发录用通知？
```

### 2. 一针见血挑出旧简历3个必死硬伤
```text
这是我目前的简历：【粘贴简历】，我要投上面这个岗位。
请不要安慰我，直接按最苛刻的筛选标准，指出人事扫一眼5秒钟就会把我刷掉的3个致命硬伤，并逐段示范怎么把干巴巴的「日常职责流水账」改写成有数字、有难度的「真金白银结果账」。
```

### 3. 一对一连环压力面试预演（最关键一步！）
```text
现在正式开始模拟二面，你就是那位最讨厌水分的业务总监。
规则：每次只问我 1 个最刁钻的问题（专挑我简历里的空窗期、跨行短板或数据水分追问）。等我打字回答完之后，先毒舌指出我刚才回答里的漏洞，再给我示范一段95分的高水准真实感回答，然后抛出下一个问题，一共拷问我8轮。现在请问第1题。
```

### 4. 把平庸打杂经历提炼成「兜底把关能力」
```text
我在上一家公司主要干的是【填入日常琐碎工作，如核对合同/整理报表/对接外包】。
请帮我回忆挖掘：在这类工作里，通常有哪些一旦出错就会让公司赔钱或丢客户的风险点？请用5个简短问题引导我回忆自己曾经堵住过的漏洞，并帮我浓缩成3条体现「拍板把关与风险兜底能力」的简历亮点。
```

### 5. 反问面试官的3个高手问题
```text
面试最后环节面试官问我「你有什么想问我的吗」，针对【岗位名】，请帮我设计3个既不显得卑微讨好、又能一秒体现我已经站在入职后帮他分忧角度思考的内行问题。
```

### 6. 谈薪资防压价博弈话术
```text
对方人事目前给我的口头意向薪资是【X元】，但我心理底线是【Y元】，我的核心筹码是【填入1-2个优势】。请帮我拟定3套不同梯度的微信/电话谈薪回复原话：既不把天聊死丢掉机会，又能温和坚定地争取到总包上浮或试用期提前转正条款。
```

### 7. 空窗期 / 被裁员高情商坦诚说辞
```text
我有【X个月】的空窗期，真实原因是【如上家业务缩编裁员/家里有事】。请帮我打磨一段30秒以内的坦诚得体回应：不抱怨前东家、不编造容易穿帮的假谎言，自然落脚到这段时间我用新工具沉淀了什么可直接上手的本事。
```

### 8. 跨行业跳槽「能力迁移桥」
```text
我想从【原行业岗位】转行去应聘【目标行业岗位】。请帮我找出这两个看似不搭界的岗位底下完全相通的3项硬本事，帮我重写简历开头的100字个人简介。
```

### 9. 入职前30天站稳脚跟计划书
```text
我下周一即将入职【岗位名】。请帮我列一份低调务实的「入职前30天破冰与拿小结果清单」：第一周该找哪三类同事聊哪几个问题、第二周挑什么样的小痛点做出第一个看得见的改进、绝对要避开哪3个职场新人大忌。
```

### 10. 年度述职 / 转正答辩去官腔提炼
```text
这是我过去半年的零散干活记录：【粘贴流水账】。请删掉所有假大空的互联网黑话，帮我按「接手前有多乱 -> 我改了哪三步动作 -> 省了多少时间金钱 -> 下半年打算啃哪块硬骨头」整理成一份老板3分钟能听爽的转正述职提纲。
```

## 二、37分钟搭出「一人公司」：6个虚拟部门文件夹岗位规矩单模板

在电脑桌面新建一个总文件夹，里面建以下 6 个子文件夹，每个文件夹放一个 `岗位规矩.md` 文本文档：

1. **`01_找客源部`**：每天只抓取【你的垂直行业】公开求购/吐槽痛点的 20 条线索，按「客户痛点 / 为什么适合我们 / 切入角度」存成表格；**铁律：严禁自动给任何人发私信或邮件**。
2. **`02_写文案部`**：读取今日行业热点与我们过往真实案例，生成 3 版不同开头钩子的朋友圈/图文初稿；**铁律：严禁出现“赋能、闭环、总而言之”等机器词，每段不超两句话**。
3. **`03_客服草稿部`**：读取常见客户提问，结合价目表拟定温和专业的回复草稿；**铁律：凡涉及退款、打折、改合同条款，一律标红挂起等真人老板拍板**。
4. **`04_记账对账部`**：将每月杂乱发票截图与流水表按「办公软件 / 推广 / 差旅 / 外包」归类汇总，标出异常大额支出与即将自动续费的订阅项。
5. **`05_查资料调研部`**：针对新业务点子，20 分钟内拉出前 5 名同行怎么收费、差评集中在骂什么、我们能切哪个小缝隙的一页纸简报。
6. **`06_早8点秘书办`**：每天早上汇总上面 5 个文件夹里待拍板的事项，压缩成 **不超过 10 行的清晨选择题清单**，由真人花 3 分钟打勾放行。
