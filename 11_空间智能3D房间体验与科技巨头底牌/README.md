## 一、普通人 3 分钟零门槛体验「一张照片变立体房间」步骤

李飞飞团队（World Labs，现已正式并入苏姿丰执掌的 AMD）核心产品为 **Marble / Atlas 空间智能预览台**：

1. **挑一张最好出效果的手机原图**：
   - 推荐拍：自家客厅一角、书房桌面、咖啡馆室内、或者老家院子照片；
   - **拍摄小窍门**：画面里最好有**前景（如茶几/绿植）+ 中景（沙发/书架）+ 远景（窗户/走廊）**三层纵深，光线均匀、不要用过度模糊的人像虚化模式。
2. **打开官方网页预览入口**（电脑浏览器体验最佳）：
   - 访问 World Labs 公开演示页（`worldlabs.ai`），点击上传单张照片或直接点选页面自带的示例画廊场景。
3. **像玩游戏一样推门走进去逛**：
   - 等待数秒生成三维空间场后，按键盘 `W / A / S / D`（或手机触屏拖动）即可在原本扁平的照片里向前走动、侧头看沙发背后的光影遮挡、甚至切换微距景深镜头。
4. **三大最实用的普通人落地玩法**：
   - **看房装修留底**：看二手房或毛坯房时随手拍几张，回家后可以在立体空间里反复比对沙发餐桌尺寸会不会挡过道；
   - **手作/家居网店展示**：一张自然光实拍图即可录出电影级环绕推拉运镜短视频，省下搭棚滑轨成本；
   - **家庭记忆封存**：把父母老房子或孩子小时候房间的老照片转成立体空间保存下来。
